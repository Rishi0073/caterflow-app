# CaterFlow - Catering Job Platform 🍽️✨

A high-performance Flutter mobile application built for catering and hospitality professionals to discover, apply for, and manage event gigs.

![Flutter](https://img.shields.io/badge/Flutter-3.x-02569B?logo=flutter)
![Dart](https://img.shields.io/badge/Dart-3.x-0175C2?logo=dart)
![Firebase](https://img.shields.io/badge/Firebase-Ready-FFCA28?logo=firebase)
![License](https://img.shields.io/badge/License-MIT-blue.svg)

---

## 🚀 Key Features

- **Job Exploration**: Browse live catering and hospitality gigs with location, pay rate, and event type.
- **Detailed Event Briefings**: Inspect requirements, dress codes, meal allowances, and reporting locations before accepting gigs.
- **Earnings & Payout Dashboard**: Real-time breakdown of daily earnings, pending settlements, and completed shifts.
- **Profile & Credentials Management**: Showcase roles (e.g. Lead Server, Buffet Coordinator, Bartender), certifications, and experience.

---

## 🛠️ Architecture & Tech Stack

- **Framework**: [Flutter](https://flutter.dev) (Null Safety)
- **State Management & Async**: Native Flutter Reactive Architecture
- **Backend Services**: Firebase Authentication & Cloud Firestore integration ready
- **Platforms**: Android & iOS

## 📦 Getting Started

### Prerequisites
- Flutter SDK `>=3.0.0`
- Dart SDK `>=3.0.0`
- Android Studio or VS Code with Flutter extension

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Rishi0073/caterflow-app.git
   cd caterflow-app
   ```

2. **Install dependencies**:
   ```bash
   flutter pub get
   ```

3. **Run on connected device/emulator**:
   ```bash
   flutter run
   ```
